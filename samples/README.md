# サンプル出力（高知県）

`npm run all` を実行して得られる `output/osm/` のうち、高知県の分だけを置いています。
スクリプトを回さずに、変換結果の中身を確かめるためのものです。

生成物の全体はリポジトリに含めていません。
理由と再現の手順は [リポジトリの README](../README.md) にあります。

## 見方

GitHub 上でファイル名をクリックすると、`.geojson` は地図として、`.csv` は表として表示されます。
ダウンロードも、別のソフトも要りません。

`.geojson` を手元で見る場合は、[geojson.io](https://geojson.io) にドラッグするか、JOSM で開けます。
`.csv` は表計算ソフトでそのまま開けます。

中身は同じで、形式だけが違います。

## 列の読み方

CSV の列は2種類に分かれます。

OSM のタグになる列は、列名がそのままタグのキーです。
`amenity`、`healthcare`、`name`、`opening_hours`、`healthcare:speciality`、`emergency`、`addr:*`、`beds`、`source` などが該当します。
空欄の列は、その施設にはそのタグを出さないという意味です。

OSM のタグにならない列は9つで、作業用の情報です。

| 列 | 意味 |
|---|---|
| `ID` | 元データの施設ID |
| `都道府県コード` | 全国ファイルを県別に分けるときの鍵 |
| `lat` / `lon` | 座標 |
| `座標の出典` | `元データ` か `ジオコーディング` |
| `要確認` | 人の目で確かめてほしい行に `yes` が立つ |
| `備考` | その行で何を判断したかを日本語で書いたもの |
| `未解釈の文字列` | 住所を構造化したときに、どの要素にも割り当てられなかった残り |
| `fixme の内容` | 元データ側の記入に不備があるとみなした内容 |

`備考` がこのデータの要点です。
スクリプトが値を落としたり、置き換えたり、短縮したりしたときは、必ずここに理由が書かれます。
`備考` が空の行は、元データをそのままタグに移しただけの行です。

## 代表的な行

判断が入っている行を4つ挙げます。
ファイル内で施設IDを検索すると見つかります。

**`healthcare:speciality` が `general` の1語に潰れた病院**
`39_高知県_hospital.csv` の `3911393100540`（高知県・高知市病院企業団立高知医療センター）です。
診療科が多く、すべてを並べると255文字の上限を超えるため、`general` の1語にしています。
救急科の有無だけは `emergency=yes` として別に残しています。

**元データの座標を捨ててジオコーダの座標を採った診療所**
`39_高知県_clinic.csv` の `3922393103160`（レディスクリニックコスモス）です。
`備考` に、捨てた座標の値と、採らなかった理由が書かれています。

**誤った町字が出たため `addr:neighbourhood` を出さなかった診療所**
`39_高知県_clinic.csv` の `3922393109400`（かわず皮フ科）です。
住所の構造化で入力と別の町字が出たため、タグを出さずに修正候補を `備考` に回しています。
元の住所文字列は `addr:full` に残るので、情報は失われていません。

**`opening_hours` が255文字を超えて短縮された薬局**
`39_高知県_pharmacy.csv` の `3955395001580`（ケンコー薬局）です。
休診日の列挙が長すぎるため、末尾の規則を落としています。
落とした内容は `備考` に書かれています。

## 気づいた点の伝え方

タグの付け方や値の選び方に意見がある場合は、このリポジトリの Issue に書いてください。
OSM へのインポートそのものについては、OSM の [Import Guidelines](https://wiki.openstreetmap.org/wiki/Import/Guidelines) に沿って進めます。

## 作り直し方

このディレクトリは `npm run samples` で作り直します。

```bash
npm run samples
```

`output/osm/` から複製するだけなので、先に `npm run build` が要ります。
別の県にする場合は `python3 scripts/build_samples.py --pref 31` のように県コードを渡します。

出力の形を変えたときは、同じコミットで流し直してください。
流し直さないと、古い出力が現在の見本として残ります。
